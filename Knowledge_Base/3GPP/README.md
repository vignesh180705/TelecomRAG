\# 3GPP Specifications and Reports



\## TS 23.501 — System Architecture for the 5G System



Describes the overall architecture of the 5G System (5GS). It defines the major network functions, such as AMF, SMF, UPF, PCF, UDM, and AUSF, along with their roles, interfaces, reference points, network slicing, PDU sessions, QoS flows, and interactions between the User Equipment (UE), RAN, and 5G Core. This document provides the fundamental architectural knowledge for understanding how the different components of a 5G network are connected.



\## TS 23.502 — Procedures for the 5G System



Describes the operational procedures of the 5G System. It covers procedures such as UE registration, authentication, connection management, PDU session establishment and release, service requests, mobility, handover, and network slice selection. It provides procedural and interaction-level information showing how different 5G network functions work together during network operations.



\## TS 23.503 — Policy and Charging Control Framework for the 5G System



Describes the policy and charging control framework used in the 5G System. It explains policy control, QoS policies, PCC rules, charging control, and the interactions between functions such as the PCF, SMF, UPF, and Application Function (AF). The document provides knowledge about how network policies and application requirements influence QoS and traffic treatment.



\## TS 38.300 — NR; NR and NG-RAN Overall Description



Provides an overall description of 5G New Radio (NR) and the NG-RAN. It describes the architecture and functionality of the gNB, CU, DU, NG-RAN, interfaces such as NG and Xn, and the interaction between the RAN and the 5G Core. It provides the main radio-access-side context needed to connect UE and RAN concepts with the 5G Core architecture.



\## TS 38.304 — NR; User Equipment (UE) Procedures in Idle Mode and RRC Inactive State



Describes UE behavior and procedures when the UE is in RRC Idle or RRC Inactive states. It covers areas such as cell selection, cell reselection, paging-related behavior, mobility, and the UE's interaction with serving and neighboring cells. This document provides detailed knowledge about UE mobility and radio-state behavior.



\## TS 38.306 — NR; User Equipment (UE) Radio Access Capabilities



Describes the radio access capabilities supported by NR User Equipment. It covers capabilities related to supported frequency bands, bandwidth, carrier aggregation, MIMO, modulation, frequency ranges, and other radio capabilities. The document provides information for understanding how UE capabilities affect compatibility and operation within an NR network.



\## TR 22.870 — Study on 6G Use Cases and Service Requirements



Studies potential use cases and service requirements for 6G. It provides information about emerging 6G services, scenarios, capabilities, and requirements that may influence future network design. The document is useful for understanding the service-level and application-level motivations behind 6G development and how future services may require capabilities beyond current 5G systems.



\## TR 38.914 — Study on 6G Scenarios and Requirements



Studies potential 6G radio scenarios and RAN-related requirements. It provides information about possible deployment scenarios, radio requirements, performance expectations, and capabilities that may be relevant to future 6G radio access networks. The document complements TR 22.870 by connecting future 6G service requirements with the radio and RAN perspective.
